# 小貝爾與火馬：南瓜燈迷徑

TypeScript / Phaser / Vite 可玩遊戲。固定可跳過教學＋種子生成正式關；每局由十題萬聖節題庫抽三道不重複題目，各四選一。保留透明角色動畫、選單及關卡音樂、互動音效。執行不使用 AI API 或玩家金鑰。

## 啟動與建置

```sh
npm install
npm run dev
npm test
npm run build
npx vite preview --host 127.0.0.1
```

開發網址預設 http://localhost:5173/ 。部署內容是 dist/ 內靜態檔案，必須透過 HTTP 開啟。生成素材前的角色去背已完成，遊戲執行只讀本機靜態資產。

## 操作與重現

- 開頭選單可輸入種子，再按「開始冒險」。例如 http://localhost:5173/?seed=42 會預填 42，點開始即可重現。
- 方向鍵 / WASD 移動；E / 空白鍵讀題及選擇；H 提示；P / Esc 暫停；R 同種子重玩。
- 必須先到燈旁讀題，才開放該題四個實體答案格。親自走到標記上按 E 作答。讀題區沒有遠端選項按鈕。
- 答錯顯示提示、可沿原路返回；不清除前題或本題已讀進度。答對只開該題門。
- 兩位角色皆在出口才通關。火馬只使用與玩家相同的通行規則與 BFS，沒有穿牆或傳送追趕。
- 畫面顯示種子、生成器版本、成功嘗試次數或備用圖狀態，並提供種子連結。
- 「同種子重玩」完整重設本局角色、門、時間與進度，但保留原圖與選項排列；「新的一關」產生新種子。
- 教學固定地圖與固定題目，不隨正式種子改變。可完成第一題或直接跳過，之後進入先前指定種子的正式關。
- 種子以字串處理、去除前後空白、最多 128 字；空白值轉為 pumpkin。0 與 000042 均為有效且不同的種子。
- 最佳時間以種子分開儲存；不儲存中途進度。

## 生成與驗證

正式關使用 FNV-1a / Mulberry32，加上獨立的題目、選項及地圖亂數串流。三個題目區以單一門障串接，隨機改變主路轉折、燈與門的列位置、支路分布及長度。不是完全自由拓樸迷宮；三區順序固定，區內路線會變化。

每次生成後檢查：

1. 三題不重複、四個選項 ID 一一對應題庫、所有特殊位置有效且不重疊。
2. 全開狀態下所有通路連通。
3. 八種門障開關組合的燈區可達性與出口可達性，防止繞過任一道鎖門。
4. 未讀題不能進答案格；讀題後四個答案均可到達並安全返回。
5. 每條相鄰通路邊取樣角色碰撞矩形，確保不侵入牆格。玩家與火馬共用同一通行函式。

每個正式種子最多嘗試四次，失敗紀錄存於 level.failures。四次失敗後改用固定備用地形，仍保留該種子的抽題及選項排列；備用圖也必須通過同一驗證器才交給遊戲。正常種子測試未觸發自然失敗；測試透過注入損壞地圖與例外，確認重試及備用路徑實際執行。

格子 34px、通道一格寬，兩角色邏輯碰撞尺寸同為 0.64 格（21.76px），四方向逐格移動。39px 角色圖片及重疊時的視覺偏移是美術呈現，不額外擴大碰撞體。

重現需相同生成器版本與題庫版本。本版為 pumpkin-v1；之後若改生成規則、題庫組成或排列，應更新版本並保存舊版本以重現舊報告。

## 架構與題庫擴充

| 檔案 | 職責 |
| --- | --- |
| src/questions.ts | 題庫資料與資料檢查，題目／選項／標準答案／提示皆有永久語意 ID |
| src/level.ts | 關卡資料型別、種子正規化、格子及碰撞尺寸 |
| src/random.ts | 確定性亂數與 Fisher–Yates 洗牌 |
| src/generator.ts | 隨機抽題、路線生成、有限重試、備用地形、固定教學 |
| src/navigation.ts | 兩角色及驗證器共用的通行、可達性與 BFS |
| src/validation.ts | 生成後自動檢查 |
| src/state.ts / commands.ts | 每局狀態與統一指令 |
| src/core.ts | 讀題、ID 答案判定、門障、火馬狀態與通關；不依賴 DOM / Phaser |
| src/input.ts / main.ts / style.css | 輸入對應、畫面與角色動畫 |
| src/audio.ts / save.ts | 音訊生命週期、各種子的最佳紀錄 |
| scripts/validate_seeds.ts | 1,000 種子批次檢查、完整走圖與故障注入，輸出 SEED-VALIDATION.json |

新增題目只要在 questions.ts 新增 question(...) 資料。選項使用例如 lantern-light.led 的永久 ID；answer.optionId 指向正答 ID。畫面上的 A/B/C/D 只代表本局位置。修改文字不用改 ID，不要把既有 ID 重新指派給其他意義。新增資料不需改核心引擎。

## 素材與音訊

public/characters/ 保留原始 JPEG、AI 去背整理中間圖、每角色四姿勢 PNG、1024×256 圖集，以及 256×256 七格循環 APNG。選單使用轉身 APNG，關卡按方向切圖並做呼吸／移動起伏；朝上沿用斜向姿勢，尚非完整四方向步態。AI 整理不是原圖無損像素裁切。

public/audio/ 有兩段各 16 秒合成循環曲與七種互動音效。點「開啟音樂與音效」才播放，支援靜音與暫停。已確認媒體檔案及瀏覽器播放狀態，未做人工聽感驗收。

## 實測與限制

詳見 TEST-RESULTS.md 的最新隨機關卡章節與 SEED-VALIDATION.json。

```sh
npx tsx scripts/validate_seeds.ts
node scripts/verify_assets.mjs
```

- 13 項測試通過；1,000 個種子驗證／重現檢查，前 100 個含九次錯答與完整通關。
- 另有八個具名種子全程案例，以及 retry-case、fallback-case 故障注入案例。
- Vite 建置成功；Phaser 約 1.5MB 主包有大小提醒。
- 尚未全面測試行動裝置及跨瀏覽器。窄側欄會縮小整張地圖，可加寬預覽操作。
- 素材、音樂、核心規則及本輪隨機功能均為本機專案；沒有發布到公開網站。

提示行為：碰壁或鎖門不覆蓋文字；答錯列出所選選項的具體原因。離開題目區會清除該區文字，但已讀與已完成進度保留。新增題目時，錯誤選項需在 src/wrongReasons.ts 依永久選項ID填入原因。

## 雲端試算表主表與Excel更新（本輪最新流程）

正式維護主表改為Google試算表：https://docs.google.com/spreadsheets/d/1IFCBjHPDCmoRls7V3dO4wv50TpVyX-HKgQn-THIjwVw/edit#gid=0 。原Google文件只保留檢閱用途。

日常只做三步：

1. 遊戲選單按「① 編輯雲端題庫」，修改「題庫」工作表。
2. 按「② 下載Excel」，取得最新.xlsx。
3. 按「③ 選擇Excel更新遊戲」，選剛下載的檔案，看到更新成功即可。

這是手動更新，不是雲端即時同步；更新題庫會保存在目前瀏覽器，重新整理仍保留。更換瀏覽器需再匯入。完全不需要Chrome擴充功能存取本機檔案網址權限。

主表包含每列一題、啟用、分類、題目、四選項、正答字母、提示及四欄錯因。標題已凍結、篩選器已開啟、長文字換行，B及O～T系統ID欄已隱藏。新增題目填獨特題目ID，其餘空白ID會自動產生；至少三題啟用。另有「使用說明」分頁。

遊戲讀取.xlsx的「題庫」分頁，也支援同欄位CSV及既有JSON。Excel解析器延遲載入，核心仍只處理經驗證的題庫資料。雲端匯出的Excel備份在cloud-question-bank/萬聖節100題-維護主表.xlsx。

## 連續遊玩

開始正式關即自動計時，畫面顯示本關與累計遊戲時間、完成關數。兩位角色通關後展示成績並倒數3秒，接著自動換種子、生成新圖、抽三題，持續到玩家按「離開不玩」。下一關種子由本次起始種子和關數推導，可重現而不重複上一關。

暫停會凍結角色、本關／累計時間與換關倒數。通關展示時間不計入累計遊戲時間。離開回選單後停止計時與自動換關，並顯示本次完成關數與累計時間。

## 玩家介面／設計師維護分離（最新）

玩家開頭只提供隨機種子按鈕、種子顯示、開始、教學與音訊控制；不顯示題庫連結、Excel下載、匯入、題庫版本或手動種子輸入。

設計師維護改用本機 http://localhost:5173/designer.html 。這是本機開發工作頁，沒有宣稱登入權限控管；預設npm run build只建置玩家index.html，dist不含designer.html或其維護程式入口。對外發布請使用dist，不要直接公開開發伺服器。

設計師匯入的題庫仍供同一瀏覽器玩家頁讀取，更新後重新整理玩家頁。正式伺服器題庫需由設計師維護public/data/halloween-100-v2.json並重新建置。

## 教學與預設聲音（2026-10-21）
- 操作教學使用獨立的三題操作題庫 `src/tutorial-bank.json`：移動、走到答案格按 E、雙角色出口條件；保留 H 提示、P 暫停與跳過。
- 教學答對第一題只開第一道門，三題皆答對且兩位角色抵達出口才完成。3 秒後進入原種子的正式第 1 關，不增加正式完成數、不儲存教學最佳成績。
- 點擊開始冒險、操作教學、跳過教學、新的一關或重玩時預設開啟音樂與音效；可手動靜音。自動換關保留當下音訊偏好。
- 驗證：`npm test` 30/30 通過；`npm run build` 通過（Phaser 主包大小提示仍存在）。瀏覽器實走種子 `cf865ebc` 的三題固定教學，進度依序 1/3、2/3、3/3，雙角色出口後回到正式第 1 關，種子保留、完成數 0。啟動教學後 audio.readyState=4、paused=false，來源 /audio/level.wav；自動轉正式關仍播放。音效的啟用與暫停/靜音清除由 FakeAudio 測試驗證，未進行人工聽音品質評估。
